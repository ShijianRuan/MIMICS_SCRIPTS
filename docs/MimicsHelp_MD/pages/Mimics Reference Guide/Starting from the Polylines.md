#### Starting from the Polylines tab page

By selecting a polylines set in the Polylines tab page of the Project management and by clicking the Iges Export button, the selected polyline set is exported as an Iges file. The entities used are of type 106 and form 12 (linear path entity).

The advantage of starting the Iges export from a polyline set is that only the contours of interest are exported. The disadvantage is that interpolation between the contours (interlayer) is not possible.

The same filters are available as in the RP Slice module.
