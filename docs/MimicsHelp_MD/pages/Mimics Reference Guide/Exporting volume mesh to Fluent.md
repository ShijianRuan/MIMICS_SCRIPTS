#### Exporting volume mesh to Fluent

When exporting a Volume mesh created in Mimics Innovation Suite to Fluent, simply chose the Export Mesh button in the FEA Mesh tab in Project management section. You can also export the mesh by going to FEA/CFD� Export option. In the following dialog, select your mesh file and click Add. Chose Fluent files (.msh) option from the dropdown in Output Format and press Add. Then click OK.
