#### With a Profile Line

To use a profile line for thresholding, select the Draw Profile line button in from the tools toolbar. To draw the line, click the left mouse button to indicate the starting point of the profile line. Then, click the left mouse button again to determine the end point of this line. Now you can use the measurements made with the profile line to determine the lower and upper threshold values. 

When Start Thresholding is enabled on the Profile Line dialog box, you can easily change the lower and upper threshold values by grabbing and moving the green lines. These lines represent the lower and upper threshold values.
