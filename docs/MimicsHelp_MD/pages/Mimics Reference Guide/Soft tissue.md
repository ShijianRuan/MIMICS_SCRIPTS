#### Soft tissue  
  
After you simulated the maxillofacial surgery with the Simulation functions (osteotomy or distraction), you can check how the soft tissue will change according to the new bone positions.

The Soft tissue module also allows you to map a picture of the patient on top of the soft-tissue.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000260.png)

**Disclaimer** : A soft tissue simulation displays a prediction of the behavior of the patient�s soft tissue after surgically repositioning segments of the facial skeleton. Although the biomechanical algorithm behind the simulation has been successfully validated on real-life orthognathic cases, no guarantees are given to the accuracy of the predicted outcome on specific patients or other surgical routines. Interpret the results with clinical judgment.

##### Soft-tissue simulation

To launch a new Soft tissue simulation, select the corresponding option from the Soft tissue menu.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000261.png)

The following window will pop up, and the 3D objects in the 3D window will disappear.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000262.png)

First select the postoperative hard tissue objects. The ones you select will also become visible in the 3D window.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000263_129x170.png) ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000264_180x170.png)

Note: For optimal results of the Soft tissue simulation, the spine should be included as hard tissue. If the spine is not segmented, you can go to the Segment menu and segment in a very easy way the spine.

Then select the pre operative Soft tissue object. The selection will become visible in the 3D window.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000265_129x170.png) ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000266_184x170.png)

Click Next and the Soft tissue simulation will start calculating. A progress bar on the bottom shows you how long the calculation will take.

Note: The calculation time depends on the performance of your computer and the size of the data. It can range from a few seconds to a few minutes.

Once the calculation is completed, the Soft tissue simulation will appear on your screen. To see the simulation, click the Play button. The speed of the animation can be adjusted by using the Speed bar.

##### Photo Mapping

To launch a new Photo Mapping, select the corresponding option from the Soft tissue menu.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000267.png)

The following window will pop up:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000268_448x319.png)

From the Object to photo map list select the pre-operative soft-tissue. Click on Load to browse to the picture of the patient.

Now indicate landmark points on the patient picture and indicate them on the 3D. Check the preview checkbox to see how the photo mapped 3D model looks like. Click ok to see the 3D model in the application.
