#### List of Landmark points  
  
Name |  Name of the object. By clicking on the name of the object, it can be changed.  
---|---  
Add Point |  Allows you to add a set of landmark points. You can do this by left clicking on the images or on a 3D object or STL to indicate the point that has to be moved and then by doing the same operation to indicate the point where the first point has to move to.
