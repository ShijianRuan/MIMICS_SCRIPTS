#### View Type

![](Mimics Reference Guide/../Resources/Images/View_type.png)

Mimics is used by a wide variety of users. To cater to the viewing conventions and make Mimics easy to use, you can set the default viewing mode for DICOM images. Mimics offers three different DICOM views as explained below. 

Note: Changing the view type does not change the orientation of the images. It only changes how the images appear on Mimics user interface. 

##### Mimics view:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000160.png)

This view is for users familiar with Mimics. In Mimics, the axial images appear as if the viewer is looking from bottom up, coronal images as looking from front to back, and sagittal images as if looking from right to left. 

##### Neurologist view: 

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000161.png)

A neurologist usually looks at the patent from top down. Thus, in neurologist view, the axial images appear as if the viewer is looking from top down, coronal images as looking from back to front, and sagittal images as if looking from left to right. 

##### Radiologist view:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000162.png)

A radiologist usually looks at the images on a screen. Many commercial DICOM viewers conventionally use this view type. In this view, the axial images appear as if the viewer is looking from bottom up, coronal images as if looking from front to back, and sagittal images as if looking from left to right.
