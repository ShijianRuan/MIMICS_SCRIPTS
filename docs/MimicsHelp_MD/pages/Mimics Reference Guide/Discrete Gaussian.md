### Discrete Gaussian

The Discrete Gaussian filter computes the convolution of the image with a Gaussian kernel for calculating the transformation to apply to each voxel. You can specify a value for the variance associated with the Gaussian kernel and also the maximum kernel size. This filter is used typically to smooth and reduce the image detail, preserving the edges for low variances.
