#### Material Editor

The assigned materials and their properties can be displayed and adjusted in the material editor. You can change the value of one of the fields by clicking on the value. Fields that are empty in the material editor will either not be exported or will receive a value of 0 depending on the export format.

![](Mimics Reference Guide/../Resources/Images/FEA_MaterialEditor.png)

The color of each material can be changed by double-clicking on the color box.

![](Mimics Reference Guide/../Resources/Images/FEA_MaterialEditor_SelectColor.png)
