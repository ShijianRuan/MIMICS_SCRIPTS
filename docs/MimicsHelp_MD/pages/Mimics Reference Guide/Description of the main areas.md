#### Description of the main areas

Select a 3D to export in Point Cloud format |  This area displays the Parts that are currently available in your project. Select here the desired object to process.  
---|---  
Output directory |  When you click the ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/0200014E.jpg) button a window appears. It will act like the Windows Explorer. You can look at all the drives of your computer and their directory structure. Select the location where you want your Point Cloud file to be placed.  
File name |  You can change the file name of your Point Cloud file.  
Save as type |  At this time the only possible output format is ASCII.
