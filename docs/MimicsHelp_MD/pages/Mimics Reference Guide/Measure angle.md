### Angle

This tool allows you to measure angles within the CT images, the alignment image and on 3D models. Select the ![](Mimics Reference Guide/../Resources/Images/Measure_Icon_Angle.png) icon from the Measure toolbar or select Measure > Angle from the menu.

![](Mimics Reference Guide/../Resources/Images/Measure_Angle.png)

The cursor will change to a measuring instrument. Click three points with the left mouse button to define the angle. The angle is expressed in degrees and shown on the screen. Fine adjustments can be made to the angle by dragging the center point or one of the ends to a new location.
