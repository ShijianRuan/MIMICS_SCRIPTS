#### Edit

CTRL + E |  Open the edit toolbar and go in edit mode  
---|---  
While in edit mode: |   
D |  Draw  
E |  Erase  
T |  Draw with local threshold  
ALT |  Holding the ALT key switches between Draw and Erase  
CTRL + drag left mouse button |  Resize the edit cursor  
SHIFT + Left mouse button |  Temporarily release the edit-tool and do 1-click navigation.
