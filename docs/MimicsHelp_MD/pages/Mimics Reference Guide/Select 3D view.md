#### Select 3D view

When you click on Select 3D View button ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/02000048.jpg), a list with all possible default views is displayed. Selecting an item from this list will position the 3D object according to the selected position.
