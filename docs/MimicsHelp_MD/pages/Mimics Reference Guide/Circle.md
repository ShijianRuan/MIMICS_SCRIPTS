#### Circle

##### Draw Circle

To create circles click on the icon Circle![](Mimics Reference Guide/../Resources/Images/circle_ribbon.png) in the Analyze menu. The cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B6_20x20.png). Simply click three points on the 2D images to create a circle. Changing to another slice or to another 2D window is possible.

The circle can be moved in the 2D images by dragging its center point with the left mouse button.

##### Context menu

![](Mimics Reference Guide/../Resources/Images/Analyze_ContextMenu.png)

Delete |  Deletes the selected circle.  
---|---  
Hide |  Hides the selected circle.  
Objects List |  Opens the Objects tab page in the Project Management.
