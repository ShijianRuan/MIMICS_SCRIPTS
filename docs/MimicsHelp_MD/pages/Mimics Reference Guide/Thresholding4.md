#### Thresholding

A reliable way to define an appropriate threshold is to make use of a profile line (see "**Mimi** "). Press the Profile line button ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/020002C3_25x25.jpg) and draw a line in the axial image over the cavity.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030002C4_448x347.png)

Profile line over the cavity of the mouth

See the figure above (axial image on position 374) to have an idea where to place the profile line. You get a profile like shown in the image below. You can clearly see the transition from the soft tissue to the cavity. Press the Start thresholding button.
