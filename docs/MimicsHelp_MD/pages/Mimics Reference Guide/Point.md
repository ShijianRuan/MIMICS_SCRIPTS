#### Point  
  
##### Draw Point

To create points click on the icon Point ![](Mimics Reference Guide/../Resources/Images/point_ribbons.png) in the Analyze menu. The cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B1_21x20.png) . Simply click on the 2D images to create a point.

The point can be moved in the 2D images and 3D view by dragging it with the left mouse button.

**Note** : Starting from Mimics 18.0, it is possible to create multiple points in a single action. The create point mode can be deactivated by using Esc key, right mouse button, or by opening another tool.

##### Context menu

![](Mimics Reference Guide/../Resources/Images/Analyze_ContextMenu.png)

Delete |  Deletes the selected point.  
---|---  
Hide |  Hides the selected point.  
Objects List |  Opens the Objects tab page in the Project Management.
