### 2D Mask Area

Allows exporting a text file with the area of the mask for the specified images of a certain view.

![](Mimics Reference Guide/../Resources/Images/Export_2DMaskArea.png)

Description of the main areas

Mask |  This area displays the masks that are currently available in your project. Select here the desired mask to process.  
---|---  
Images |  You can choose for which view you want to export the mask area.  
Range |  You can calculate the area of the mask for all the slices in the chosen view, for the slice that is displayed in the screen or for a specified range of images.  
Filename |  The name of the generated text file  
Path |  When you click the ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/0200014B.jpg) button a window appears. It will act like the Windows Explorer. You can look at all the drives of your computer and their directory structure. Select the location where you want your gray values file to be placed.
