### Profile Line  
  
Visualizes an intensity profile of the Hounsfield Units (HU) or Gray Values (GV) along a user defined line. To draw this line, click the left mouse button to indicate the starting point of the profile line, move the mouse to the end position of the line and click again. The Profile dialog graph will be displayed:
