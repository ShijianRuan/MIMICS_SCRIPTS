### Base

Mimics interactively reads CT/MRI data in the DICOM format. Segmentation and editing tools enable the user to manipulate the data to select bone, soft tissue, skin, etc. Once an area of interest is separated, it can be visualized in 3D. After this visualization, a file can be made to interface with STL+ or Analysis objects. CAD data, imported as STL files, can be visualized in 2D and 3D for design validation based on the anatomical geometry.

Achieve rapid, reliable image segmentation and accurate 3D reconstruction using validated technology.

  * Import and anonymize medical data
  * Process your medical images: filter, crop, re-slice and more
  * Segment medical images using intuitive, state-of-the-art tools
  * Convert 2D image stacks to 3D models and visualize contours
  * Optimize 3D models with fixing tools like smooth, wrap, fill holes and more
  * Make measurements on images or 3D models
  * Align objects using global or point based registrations
  * Export 3D models as STL files for 3D printing, design or analysis
