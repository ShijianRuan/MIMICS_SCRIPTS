#### Draw a spline

This function allows you to draw a spline that represents the thin structure. These are the steps to perform:

  * Select the Create Spline tool. The cursor will change to a pencil.


  * Start drawing the spline: for every change in direction along the spline, you need to click (press and release the left mouse button) once to define the course of the spline. In order to terminate the spline, double click the left mouse button or click the right mouse button.


  * While drawing the splineyou can scroll through the images with the cursor keys and follow the nerve channel if needed.


  * Fine adjustments can be made by dragging the points to a new location. The spline can be moved entirely by dragging the orange line.
