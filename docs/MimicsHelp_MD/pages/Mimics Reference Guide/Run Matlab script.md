### Run Matlab script

Mimics allows you to run a custom Matlab script on some of the Mimics objects. Note:you need a valid Matlab license to use this function.

When you chose the Run Matlab script option, the following window will appear. Here, create a new script in the Script editor section or load an existing script by clicking on Open and browsing to your script.
