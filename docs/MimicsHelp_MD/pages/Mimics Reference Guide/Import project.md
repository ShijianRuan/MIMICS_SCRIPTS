### Import project

This function allows you to load a Mimics or 3-matic project into the current project. 

![](Mimics Reference Guide/../Resources/Images/ImportProject.png)

For Mimics files of the current version |  Images, parts, objects, polylines and primitives will be imported. All the imported objects will be preserve the link to images that they had before importing. The object that were not linked to images will remain unlinked.  
---|---  
For Mimics files up to Mimics 20 version | Images, parts, objects, polylines and primitives will be imported. All the objects of the imported project will be linked to the imported images.  
For 3-matic files |  Images, parts, objects, polylines and primitives will be imported. The imported objects are not linked to images.  
  
Note: You can only load a Mimics or a 3-matic project if a project is already open.
