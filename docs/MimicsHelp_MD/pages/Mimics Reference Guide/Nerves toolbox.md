### Trace Thin Structure  
  
This tool allows you to create a representation of thin structures such as a nerve or an annulus. The thin structure is drawn manually and consists of a series of points, connected by an interpolated line. The object that is created is a spline. To activate the toolbox, select the Trace Thin Structure icon ![](Mimics Reference Guide/../Resources/Images/tracethinstructureiconribbons.png)in the Segment menu or click **New** -> **Thin Structure** in the Objects Project Management tab. The thin structure toolbar will appear on the screen. Each time only the relevant buttons are enabled in the toolbar. Close the toolbar by clicking on the red cross in the top right corner.
