#### Supported Scanners and Modalities

**Supported Modalities**

Mimics supports the mentioned imaging modalities.

  * CT
  * MRI
  * Micro CT
  * CBCT
  * 3D Ultrasound (Supported only in Mimics Research Edition)
  * X-ray (Supported only in Mimics Research Edition)


##### Supported Scanners

Beside these image formats that are supported by the Mimics base module, we also offer different Import Modules. With every Import Module, you can import several proprietary formats from scanner manufacturers. Different types of media and devices are supported.
