#### Loading second dataset

The second dataset can be loaded in two ways.

![](Mimics Reference Guide/../Resources/Images/Import.PNG) | Import dataset directly in the image registration interface  
---|---  
![](Mimics Reference Guide/../Resources/Images/Open.png) | Open previously created project in the image registration interface  
  
The second dataset will be visualized on right image views:

![](Mimics Reference Guide/../Resources/Images/ImageRegistration_Window_621x347.png)

The active image views can be expanded and minimized by pressing the _Space Bar_ key.

![](Mimics Reference Guide/../Resources/Images/ImageRegistration_ExpandedWindow_621x347.png)

**Panning and Zooming**

To activate and deactivate synchronized panning and zooming options use the following shortcut keys.

  * O � pan in all views in 1 dataset (pressing O will deactivate)
  * P � pan between 2 datasets (pressing P will deactivate)
  * X � zoom between 2 datasets (pressing X will deactivate)
  * Z � zoom between all views in 1 dataset (pressing Z will deactivate)
