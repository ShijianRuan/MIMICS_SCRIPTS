#### Sphere

##### Draw Sphere

To create spheres click on the icon Sphere![](Mimics Reference Guide/../Resources/Images/sphere_ribbons.png) in the Analyze menu.The cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B6_23x23.png). Simply click four points on the 2D images to create a sphere. Changing to another slice or to another 2D window is possible.

The sphere can be moved in the 2D images by dragging the control points with the left mouse button.

##### Context menu

![](Mimics Reference Guide/../Resources/Images/Analyze_ContextMenu.png)

Delete |  Deletes the selected sphere.  
---|---  
Hide |  Hides the selected sphere.  
Objects List |  Opens the Objects tab page in the Project Management.
