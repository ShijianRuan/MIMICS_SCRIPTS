### Cavity Fill from Polylines

The cavity Fill from Polylines will create a mask by filling every polyline in a polyline set.

![](Mimics Reference Guide/../Resources/Images/CavityFillFromPolylines.png)

Source polyline set and target mask are set here.

Note: Please be aware that because the cavity fill from polylines, fills polylines that are calculated from a mask and interpolated during this calculation, your new mask can be a bit larger than the original mask. Please explore the [Cavity Fill](<Cavity%20Fill.md>) operation if you would like to obtain the exact mask.
