#### Import a mesh in Patran

The exported surface or volume mesh can be imported in Patran by going to the File menu and choosing Import. This will open the following dialog:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001FB_408x207.png)

##### Convert a surface mesh to a volumetric mesh

If you start with a surface mesh, choose the Elements button in the toolbar and choose to create a solid mesh. Select a Tetmesh with Tet4 or Tet10 elements. Have a look at the settings below how to do this:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001FC_412x300.png)

Next, choose to select triangles and select all triangles in the mesh. After clicking on the Apply button, a volume mesh will be generated.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001FD_411x299.png)
