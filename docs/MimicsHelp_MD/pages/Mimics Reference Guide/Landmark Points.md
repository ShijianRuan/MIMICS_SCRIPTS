#### Landmark Points

The landmark points are used to mark the matching positions on both datasets. All the landmark points are shown in the Landmark Points table.

![](Mimics Reference Guide/../Resources/Images/LandmarkPoints.PNG)

Add | Adds a set of landmark points on the image  
---|---  
Delete | Removes a set of landmark points from the image  
Locate | Navigates to the location of the selected landmark point on the image  
  
Landmark points are placed in pairs, therefore to complete the pair, after creating first point on dataset 1 place second point on dataset 2. The landmark points can be moved by left-clicking on one of the landmark points in the views and dragging the points. To initiate Image Registration tool at least 3 landmark points are required, however more landmark points can be used as well.
