### Distance

This tool allows you to measure distances within the images and on 3D models. Select the ![](Mimics Reference Guide/../Resources/Images/Measure_Icon_Distance.png) icon from the Measure toolbar or select Measure > Distance from the menu.

![](Mimics Reference Guide/../Resources/Images/Measure_Distance.png)

The cursor will change in a measuring rule. Click once the left mouse button to set the first point. A measurement will be shown together with its length (expressed in mm). Click again to fix the other end of the measurement. Fine adjustments can be made to the measurement by dragging either end to a new location.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/020000E9.jpg) |  ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/020000EA_162x148.jpg)
