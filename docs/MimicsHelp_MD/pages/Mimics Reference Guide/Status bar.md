### Status Bar

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030000D1.png)

A status bar is displayed along the bottom of the screen. If the status bar is not displayed, select View > Status Bar from the menu bar. You can remove the status bar by selecting View > Status Bar from the menu bar again. The status bar displays the following useful information:

  * tips that describe actions taken by tools and menu commands


  * current gray scale value or Hounsfield unit in the voxel currently pointed at by the cursor


  * current cursor position in 3D coordinate system
