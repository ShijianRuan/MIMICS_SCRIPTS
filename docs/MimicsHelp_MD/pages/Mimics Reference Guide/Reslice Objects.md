#### Reslice Objects

![](Mimics Reference Guide/../Resources/Images/PMTab_ResliceObjects.PNG)

Reslice view can be created either along a curve or along a plane. A reslice view allows you to visualize the images in a different direction. Multiple options are available in the **View** menu and toolbar for creating reslice views. The resliced images can be viewed by selecting the respective reslice view from the **Reslice Objects** tab in Project Management area.

##### List of the created reslice objects

Name |  Name of the reslice object. By clicking on its name, it can be changed. RC stands to reslice curve, while RP stands to reslice plane.  
---|---  
Visible |  The active reslice object is indicated by means of glasses. In the Reslice layout the images corresponding to the active reslice object will be shown.  
Cross-Section Length (mm) |  The cross-section length determines the width of the cross-section images when the reslice object is a curve. This length is set to optimal by default, but can be altered by double-clicking on the Optimal text. This way you can specify an exact cross-section length. Note: To return to the Optimal setting after you have specified an exact length, set 0 as the value of the cross-section length.  
  
##### Functions on Reslice Objects

New |  Shows a menu from where you can choose to reslice along a curve or along a plane.  
---|---  
Delete |  Deletes one or more reslice objects.  
Properties |  Shows the properties of the selected reslice object.  
Duplicate |  Duplicates the selected reslice object.
