#### Cylinder

##### Draw Cylinder

To create cylinders click on the icon Cylinder![](Mimics Reference Guide/../Resources/Images/cylinder_ribbon.png) in the Analyze menu. The cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B6.png). Simply click a start and end point of the cylinder axis, followed by a point which indicates the radius on the 2D images to create a cylinder (see figure).

The cylinder can be moved and in the 2D images by dragging the control points with the left mouse button.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001C1.png)

##### Context menu
