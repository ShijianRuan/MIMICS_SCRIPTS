### Calculate Mask from Object

The calculate mask from 3D will create a mask from a Part or an STL. The mask is created by taking the contours of the Part or STL on each slice of the project and then by filling the contour with a mask.

![](Mimics Reference Guide/../Resources/Images/CalculateMaskFromObject.png)

The source 3D object or STL and the target mask can be indicated in the dialog.
