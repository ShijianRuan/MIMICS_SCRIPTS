#### Plane

##### Draw Plane

To create planes click on the icon Plane![](Mimics Reference Guide/../Resources/Images/plane_ribbons.png) in the Analyze menuThe cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B6_25x25.png). Simply click three points on the 2D images to create a plane.

The plane can be moved in the 2D images by dragging the control points with the left mouse button.

##### Context menu

![](Mimics Reference Guide/../Resources/Images/Analyze_ContextMenu.png)

Delete |  Deletes the selected plane.  
---|---  
Hide |  Hides the selected plane.  
Objects List |  Opens the Objects tab page in the Project Management.  
  
##### Actions

![](Mimics Reference Guide/../Resources/Images/image15.png)

Create reslice plane(s): to create one or more reslices along the plane(s) selected. Both normal, and Analysis planes can be used.

Create Fluoroscopy view: to create fluoroscopy view based on this plane
