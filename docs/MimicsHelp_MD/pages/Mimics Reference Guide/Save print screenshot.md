### Save/Print Screenshot

After selecting the image type on the left of the screen, you will immediately see a preview on the right. You can select 2 destinations:

  * To a file: Select Filename in the Destination frame to save the image as a BMP or JPEG file. A default name will be proposed (patient name + view) and the default folder will be the folder where the project is stored. You can browse to a new folder by using the yellow button on the right.


  * To the printer: select Printer to print the image


  * To clipboard: copies the image to the clipboard allowing you to paste it into another application


The image or the print will show you exactly the same information that is on the screen, so you will have to prepare your screen with rulers, measurements, etc first before creating the image or print.
