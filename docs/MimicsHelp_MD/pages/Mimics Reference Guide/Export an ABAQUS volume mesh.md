#### Export an Abaqus volume mesh

You can export an Abaqus volume mesh by going to the Export menu and choosing Abaqus. In the following interface you can then add your volumetric mesh and export it as an Abaqus file.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000202_482x452.png)

When you select your mesh file, the Edit button will be activated. Here you can chose to export surfaces with your mesh or not and chose from the available element types. For a complete list of available element types, see chapter [Abaqus file](<Abaqus%20file.md>).

**Note** : When no value for the Poisson coefficient is defined, the default value of 0.5 will be exported in the Abaqus file.

##### Export an Abaqus surface mesh

If you want to create your volume mesh using Abaqus, you can export your surface mesh as an Abaqus file. To do this, go to the File->Export menu and choose Abaqus. This will open the following dialog:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000203_501x469.png)

Add the Parts or STL files that you want to export, set the output format as Abaqus Files (.inp) and press OK.
