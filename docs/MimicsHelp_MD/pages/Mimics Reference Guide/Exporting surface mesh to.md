#### Exporting surface mesh to Fluent 

In the export dialog chose 3D tab for exporting the surface mesh. Chose Fluent files (.msh) option from the dropdown in Output Format and press Add.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000224_438x410.png)

When you press OK, you can choose to either use the existing surfaces (use current surface split option) or to resplit using a defined angle. Click on OK.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000225_268x147.png)
