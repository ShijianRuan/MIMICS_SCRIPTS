### Toggle 3D Window  
  
To view the 3D pane in the Mimics work area in 3-panes setting, click on the 3D button on the Main Toolbar. The sagittal view will be replaced with the 3D view and a 3D toolbar.

You can also work in 4-panes setting, in which case you see all image views and a 3D view. In that case, the Toggle 3D button is not present.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/060000E5_413x135.png)

If you have not yet created a 3D, you can calculate a Part by selecting this button in the Segmentation toolbar: ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/020000E6_25x25.jpg). The Parts list dialog will be shown, listing all Parts. Click the Options button to adjust 3D generation parameters to your needs. Then click the Calculate button to start calculating the Part. The 3D is automatically shown on your screen after calculation.
