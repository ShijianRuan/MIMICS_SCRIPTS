#### Line

##### Draw Line

To create lines click on the icon Line![](Mimics Reference Guide/../Resources/Images/line_ribbon.png) in the Analyze menu. The cursor will change to ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001B6_25x25.png). Simply click a start and end point on the 2D images to create a line (Start and end point can lie in different images)

The line can be moved in the 2D images by dragging the end points with the left mouse button.

##### Context menu

![](Mimics Reference Guide/../Resources/Images/Analyze_ContextMenu.png)

Delete |  Deletes the selected line.  
---|---  
Hide |  Hides the selected line.  
Objects List |  Opens the Objects tab page in the Project Management.
