#### STL Types

This page allows you to change the preset options for assigning different 3D object types. These options will be available in 3D and STL object properties dialog for easy assignment of model type. Using this tool, it becomes easier than ever to standardize your models for sharing information among your peers. 

![](Mimics Reference Guide/../Resources/Images/STL_Types.png)

To individually customize this list, use the **Add** , **Remove** and **Reset to defaults** options. You can also chose to save the current settings in this tab by using the **Save Types** button or load a custom set of 3D types using the **Load Types** button.
