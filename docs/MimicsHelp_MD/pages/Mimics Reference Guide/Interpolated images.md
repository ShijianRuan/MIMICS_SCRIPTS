### Interpolated images

This function will allow you to toggle between an interpolated view of the reslices in XZ and YZ direction.

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030000D2_207x172.png) Interpolated Images off |  ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030000D3_207x172.png) Interpolated Images on  
---|---  
  
Note: This function will only interpolate the grey value images, the mask will remain the same. Editing on the mask on interpolated images is possible.
