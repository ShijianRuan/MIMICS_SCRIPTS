#### Import a volume mesh in Mimics

To import these files, click on the Import Mesh ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/020001FF.jpg)button in the FEA project management tab:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000211_236x207.png)

This will open a file browser:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000201.png)

Change the type of the listed files from Patran Neutral to ANSYS File, now the ANSYS cdb files and inp files will be shown. Select the appropriate file and lick Open.

Alternatively, if you are importing an element and node file pair, select the type of files to be All files. This will show all the files available in your folder. Next, select either the Element or Node file and click Open. The following dialog will appear. 

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/03000213_299x336.png)

Note: element and nodes file can be large. Please allow some time for the dialog to show up.

Browse to the remaining file. The minimal and maximum index will be filled. Also select the type of elements of which the volume mesh consists out.

Yet another alternative is to create a Prep 7 file and use it to import the volume mesh.
