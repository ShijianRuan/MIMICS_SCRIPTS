### Apply filter  
  
In the list of filters you can add, edit or remove the filters that have been applied to the image set. 

![](Mimics Reference Guide/../Resources/Images/EditFilterList.png)

New ![](Mimics Reference Guide/../Resources/Images/New_Icon.png) |  Creates a new filter.  
---|---  
Delete ![](Mimics Reference Guide/../Resources/Images/Delete_Icon.png) |  Deletes a filter.  
Move Up / Down ![](Mimics Reference Guide/../Resources/Images/MoveUpDown_Icon.png) |  Reorganizes the order of the filters.  
Help ![](Mimics Reference Guide/../Resources/Images/Help_Icon.png) |  Opens the Help pages under the Edit filter list   
  
Note: When the order of the filters is altered, these filters will be reapplied to the image set. This operation may take a few minutes.
