#### Starting from the Analysis Objects tab page

By selecting one or more Analysis objects in the Analysis Objects tab page of the Project management and by clicking the Iges Export button, the selected Analysis Objects are exported as one Iges file.

The entities used are: 

  * Analytical Geometrical objects (sphere, line, plane, �): according the standard IGES representation. For example, a sphere is exported as a circular arc revolved around an axis.


  * Free form objects (Curves, Surfaces): NURBS representation.
