#### Export a surface file to Patran

If you want to create your volume mesh using Patran, you can export your surface mesh as a neutral Patran file. To do this, go to the File->Export menu and choose Patran. This will open the following interface:

![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/030001FA_458x430.png)

You can export a Part or an STL file to a Patran neutral file, by adding the object to the list, choosing the Neutral File format and clicking on the OK button.
