### Grayvalues

Allows exporting a text file with the grayvalues of your images.

By selecting Grayvalues via File > Export , a dialog is displayed where you can choose to export masks as a text file with all the grayvalues of the voxels.

![](Mimics Reference Guide/../Resources/Images/Export_grayvalues.png)

Description of the main areas

Select a mask to export in Grayvalues |  This area displays the masks that are currently available in your project. Select here the desired mask to process.  
---|---  
Output directory |  When you click the ![](Mimics Reference Guide/../Resources/Images/Mimics%2015.0%20Reference%20Guide_track_v2_no_numbers/0200014B.jpg) button a window appears. It will act like the Windows Explorer. You can look at all the drives of your computer and their directory structure. Select the location where you want your Grayvalues file to be placed.  
File name |  You can change the file name of your Grayvalues file.  
Save as type |  At this time the only possible output format is txt (text file).  
Expressed in |  Choose between Hounsfield units and Grayvalues.
