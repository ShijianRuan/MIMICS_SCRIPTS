# 汇报图稿与截图说明

主文档见 [Mimics 医学影像标注扩展项目汇报](../project_brief_2026-10-11.md)。代码基线为 `a34805e3b6724c25353642aa40017080e9e81b7e`。

## 图稿编辑

- `workflow.drawio` 和 `architecture.drawio`：用 diagrams.net 或 draw.io 桌面版打开，每个节点、文字和连线均为可编辑对象。虚线表示需要完善的流程约束。
- 同名 `.svg`：主文档展示的矢量图，保留文字和几何对象，可在矢量编辑器修改。
- 同名 `.mmd`：Mermaid 文本源，可修改后生成新的流程图。它表达同一逻辑，不锁定 SVG 的排版。
- `build_visuals.py`：SVG 与 draw.io 的共同生成源；修改节点和连线后运行，可保持两种文件同步。单独修改 draw.io 后可直接导出 SVG，无须运行生成脚本。

## 截图来源

`import-window.png` 和 `model-manager.png` 使用当前产品 Qt 窗口代码渲染；模型行是合成演示数据。`render_screenshots.py` 可在安装 PySide6 的外部 Python 环境复跑。捕获过程隔离用户路径状态，不启动转换、训练或推理任务。

截图用于说明已有界面，不是设计效果图，不是 Windows/Mimics 实机截图，也不包含患者数据。真实影像和三视图叠加截图尚需在目标工作站取得后补充，不能用示意图替代实际结果证据。

## 汇报事实口径

仓库中历史效果记录来自有限公开 CT 任务，原始工件位于记录中的 Windows 工作区，本轮未独立重算其分割指标。不将 Dice 换算成人工节省时间，不将主动学习排序视为医学正确性证明，不将菜单存在视为全部配置已获实机验证。主文档中的后续计划是建议顺序，不含工期承诺。
