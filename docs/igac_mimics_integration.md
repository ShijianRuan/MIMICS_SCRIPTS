# IGAC 与 Mimics 集成说明

## 目标

IGAC 用于在已有 3D Mask 基础上进行交互式主动轮廓修正。Mimics 只负责启动时读取当前图像和 Mask，以及用户确认后回填最终结果；显示、交互和 LGDF 计算均在外部 PySide6 进程中运行，不持续占用 Mimics GUI 线程。

## 用户操作

1. 在 Mimics 中选中一个 Mask，运行 `02_AI/IGAC.py`。
2. 外部窗口准备完成后保持暂停，Mask 不会自行变化。
3. 大视图是当前可编辑平面，右侧两张小图是同步的正交定位视图。黄色十字光标在三张图中表示同一 3D 体素；单击小图可移动定位点，双击小图可将该方向切换为大视图。小图不能编辑 Mask，避免定位时误操作。
4. 默认使用 `Drag contour`：青色连续轮廓上的每个可见位置都可以拖动。靠近轮廓时显示一个固定外观的琥珀色控制点；按下、拖动和最终落点期间该点不改变颜色。拖动过程中，琥珀色点标识算法实际应用到的轮廓位置，青色当前轮廓随每个真实 FFD 预览连续变化；淡灰虚线保留按下前轮廓，便于在松手前比较和决定落点。
5. 需要修正一段较长边缘时使用 `Guide edge`：从青色轮廓附近按下，沿期望边缘持续移动鼠标。界面不再画一条彩色鼠标轨迹，而是显示同一个固定外观的活动控制点和实时变化的青色轮廓。每批鼠标采样都会牵引当前最近轮廓段，因此视觉语义是“边缘跟随鼠标”，不是涂抹、擦除或事后回放轨迹。
6. 作用范围固定在局部物理邻域，但普通操作时不显示遮挡图像的大圆圈。只有指针超过局部安全限幅时，才显示实际应用点到请求位置的细限幅提示，并建议分成多次短操作。
7. 鼠标移动期间只执行局部 FFD 预览。松手后 LGDF 只在本次编辑邻域短暂演化一次并自动暂停，不会在用户停止操作后持续改变其他区域。
8. 手势未松开时可按 `Esc` 或单击右键立即取消，并精确恢复鼠标按下前状态。使用 `Stop` 可立即停止后续迭代并保留当前预览，`Undo` 可完整恢复本次已完成操作之前的轮廓和约束，`Reset Mask` 恢复打开窗口时的 Mask。
9. 检查三个正交视图后，选择更新原 Mask 或创建可编辑副本，再点击 `Apply to Mimics`。关闭或取消窗口不会修改 Mimics。

常用快捷操作：鼠标滚轮切片、`Ctrl+滚轮` 缩放、中键拖动画面；`1/2` 切换单点拖动和沿边引导；方向键上下切片，`[`/`]` 调整作用半径，`Ctrl+Z` 撤销，空格停止或继续最近一次局部细化，`F` 聚焦 Mask，`I` 显示完整图像。

## 算法边界

本实现保留 IGAC 的局部高斯分布拟合（LGDF）水平集演化，并在交互层使用局部 B-spline FFD 表达用户期望的轮廓位移。普通界面不再暴露 Add、Erase、Barrier 画笔，也不根据鼠标位于 Mask 内外猜测用户意图。

`Drag contour` 不是把涂抹换一个名字。鼠标按下必须捕获当前二维切片上的真实 Mask 边界位置；拖动位移在显示平面内定义，但紧支撑三次 B-spline 在物理毫米空间中同时形变邻近切片。每个预览都由鼠标按下时的三维水平集快照推导，后台只恢复上一块受影响区域，不复制整个 3D 状态。

`Guide edge` 也不写前景或背景画刷。worker 将高频鼠标事件合并为有序轨迹，再按物理距离采样；每个采样位置把当前最近轮廓段用同一局部 FFD 牵引到鼠标位置，因此轮廓会沿移动路径连续跟随。轨迹结束后只对合并后的局部包围盒运行一次 LGDF。

实现直接形变有符号距离场，不经过 Mask 转网格再栅格化，因此不会额外引入一次表面离散化。FFD 只负责把现有边界移动到合理邻域；弱边界是否能继续贴合仍受图像对比、初始 Mask、LGDF 参数和最大自动位移限制，不应把 FFD 当作新的全自动分割模型。

本入口不再包含以下非 IGAC 行为：

- 搜索图像梯度峰值作为拖拽终点；
- 使用没有物理支持域和安全限幅的任意插值场直接扭曲 Mask；
- 把固定若干次迭代误认为已经收敛；
- 鼠标松开后无限运行。

如果需要“两点之间沿梯度寻找最优 2D 路径”，应使用 LiveWire/Intelligent Scissors。这是另一类算法，不应混入 IGAC。

## 实时性设计

单点拖动只保留尚未处理的最新指针位置；沿边引导会保留轨迹顺序并按物理距离重采样。两种操作期间都不运行 LGDF，只刷新并显示 worker 返回的真实局部 FFD 轮廓；不会用 GUI 假轮廓追赶鼠标。鼠标松开后才启动可停止、可自动收敛的局部吸附。LGDF 的计算域是本次编辑包围盒加物理邻域，不再对整个 ROI 做无谓卷积。

- GUI 线程只负责绘制图像、约束覆盖和接收鼠标事件。
- 灰度底图只在切片、方向或窗宽窗位变化时重建；轮廓动画帧只更新轻量覆盖层，避免重复进行整幅浮点 RGB 合成。
- 正常观察比例使用显示层亚像素平滑轮廓，减少体素阶梯带来的粗糙感；放大到每体素约 4 个屏幕像素时自动切回精确体素边界。平滑只作用于 `QPainterPath`，不修改 Mask、控制点坐标或最终导出结果。
- 主视图与两张正交上下文图共享一个 3D 光标。GUI 立即更新十字光标，传给 worker 的高频位置只保留最新值；worker 最多按配置频率刷新两张非活动平面，不重复计算当前主平面。
- 三个方向都按真实 voxel spacing 显示物理比例，并自动聚焦到当前 Mask 周围，避免冠状或矢状图因层厚而被错误压扁。
- 高频轨迹事件在 worker 入口合并并按毫米重采样，保留路径且不追赶过时的每一个鼠标事件；只在松手后启动一次局部演化。
- 每轮最多执行配置的少量 LGDF 迭代，然后重新检查用户命令；因此 `Stop`、`Undo` 和关闭窗口不必等待一个长迭代批次。
- 显示帧按固定时间间隔发布，过时的鼠标段合并处理，不追赶无意义的旧帧。
- 鼠标按下时保存一个精确的设备内撤销快照。只保留最近一次操作，限制额外显存占用。

“立即反馈”包含两个层次：GUI 立即显示固定外观的活动控制点，worker 连续返回局部 FFD 后的真实完整轮廓和实际应用点；LGDF 只在松手后短暂运行。单次 LGDF 迭代仍是不可中断的响应上限，因此大 ROI 的实际帧率必须在目标 GPU 上验收。

## 自动停止

停止条件基于实际二值 Mask 的变化，而不是固定迭代次数：

1. 每个计算周期统计本周期改变的体素数及其占局部计算域的比例；
2. 达到最少观察轮次后，连续多个周期低于变化阈值才判定稳定；
3. 迭代数和运行时间仅作为防止弱边界持续演化的安全上限；
4. 达到安全上限时保留当前预览、显示警告并暂停，不自动提交结果。

默认参数位于 `interactive_algorithms_config.json`：

| 配置 | 默认值 | 作用 |
|---|---:|---|
| `display_interval_seconds` | `0.06` | 外部窗口最大约 16 FPS 的结果刷新间隔；计算较慢时自动降速 |
| `context_display_interval_seconds` | `0.12` | 两张正交定位视图最大约 8 FPS 的刷新间隔；光标在 GUI 中即时联动 |
| `iterations_per_cycle` | `1` | 每次检查命令前执行的 LGDF 迭代数 |
| `convergence.minimum_iterations` | `2` | 开始判断稳定前的最少观察迭代 |
| `convergence.stable_cycles` | `2` | 连续稳定周期数 |
| `convergence.changed_voxel_ratio` | `0.0002` | 允许变化体素占局部计算域的比例 |
| `convergence.changed_voxel_limit` | `32` | 大局部区域仍允许判稳的变化体素上限 |
| `convergence.maximum_iterations` | `24` | 单次交互的迭代安全上限 |
| `convergence.maximum_seconds` | `5` | 单次交互的时间安全上限 |
| `parameters.max_displacement_mm` | `10` | 相对初始 Mask 的自动位移壳层 |

## 数据和坐标

- 图像、初始 Mask、约束和结果始终位于同一个 Mimics voxel grid。
- 外部窗口优先使用可获得的原始 CT HU 或 MRI 信号；不可用时使用具有 metadata 关系的 Mimics buffer 表达。
- 窗宽窗位只改变显示，不改变 LGDF 使用的归一化强度。
- spacing 用于高斯邻域、导数、曲率、距离场和画笔的物理毫米计算。
- 结果返回前再次验证 shape、病例身份和目标 Mask。目标 Mask 在 IGAC 打开期间被修改时，只允许创建副本，不覆盖较新的人工工作。

## 资源和失败处理

IGAC 默认优先使用 CUDA，并与其他 AI 功能共享 GPU 锁。空闲 nnInteractive 服务可在竞争时主动释放模型；真实推理正在运行时只显示等待原因，不强杀结果。CPU 回退只允许用于受限 ROI。

外部窗口关闭、取消、失败或应用结果后都会释放 GPU 锁和计算引用。Mimics 中唯一无法后台化的是启动时读取 voxel buffer 和最终一次性写回 Mask；两处均保持为短事务。中间结果不会逐帧回写 Mimics，因此 IGAC 失败不会留下半个 Mask。

## 适用范围

适合已有轮廓基本正确、局部需要扩张、阻挡泄漏或改善强度不均匀边界的 CT、MRI 和其他灰度体数据。它不负责从空 Mask 识别器官，也不能在完全不可见、严重伪影或相邻组织统计分布相同的区域推断解剖语义。此类情况应先由 nnInteractive、DINOv3 或 nnU-Net 产生初稿。

## Windows 实机验收

1. 打开窗口后等待 10 秒，未操作时 Mask 不变化。
2. 当前切片显示一条完整连续的青色轮廓，而不是离散控制点或仅显示拖动起止点。
3. 两张正交小图与大图显示同一黄色 3D 光标；小图单击定位、双击切换主平面，且任何小图操作都不修改 Mask。
4. 冠状、矢状和轴向视图按 spacing 保持正确物理比例，不出现非等距数据被错误拉伸或压扁。
5. `Drag contour` 可从任意可见轮廓位置启动；活动控制点从捕获到落下始终保持同一颜色，拖动期间当前青色轮廓持续变化，淡灰虚线保留原轮廓。远离轮廓按下只显示短暂未捕获反馈，不改变 Mask，也不消耗一次撤销。
6. `Guide edge` 不显示涂抹轨迹或绿色、红色覆盖层；按住滑动时活动控制点和附近当前轮廓共同跟随鼠标，松手前即可判断修正效果。
7. 鼠标按下和移动期间可看到轮廓更新，不必等待抬起；快速移动不会形成越来越长的响应积压。
8. 两种操作均只改变作用半径附近；松手后仅运行一次局部细化，并在收敛或安全上限处自动暂停。
9. 拖动或引导期间按 `Esc`、单击右键可取消当前手势并恢复按下前状态；`Stop` 在当前 LGDF 小周期结束后生效，`Undo` 精确恢复上一操作，`Reset Mask` 恢复初始 Mask。
10. 达到时间或迭代安全上限时显示警告但不提交结果。
11. `Cancel` 不修改 Mimics；`Apply to Mimics` 只产生一次可撤销事务。
12. nnInteractive 完成后立即打开 IGAC，空闲模型及时释放，不出现无原因等待。
